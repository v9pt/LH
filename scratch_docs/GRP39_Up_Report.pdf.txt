Abstract
Low-light face image super-resolution is an important research area in computer
vision because facial images captured under poor illumination conditions often suffer
from blur, noise, low contrast, and loss of important facial details. These degradations
reduce the performance of surveillance systems, biometric authentication frameworks,
and face recognition applications. Conventional interpolation and enhancement meth-
ods generally fail to reconstruct realistic high-frequency facial textures and identity-
preserving information.
This research proposes a Neuro-Fuzzy Inferencing Based Low-Light Face Super-
Resolution System that combines Adaptive Neuro-Fuzzy Inference Systems (ANFIS),
locality constrained representation, motion blur correction, regression-based recon-
struction, and deep neural refinement techniques to improve low-light facial image
quality. The framework first estimates the darkness level of the image using ANFIS-
based adaptive learning. Based on the estimated illumination conditions, adaptive
enhancement and motion blur correction techniques are applied to improve visibility
and restore structural consistency.
The enhanced image is then processed using locality constrained dictionary repre-
sentation and regression-based patch reconstruction methods in order to recover im-
portant facial textures and high-resolution details. Finally, RRDB-based neural refine-
ment modules improve perceptual quality and generate sharper facial outputs while
preserving identity-related features.
The proposed system is implemented using Python, PyTorch, OpenCV , and scikit-
fuzzy, while the CelebA dataset is used for training and evaluation. Experimental
evaluation using PSNR, SSIM, LPIPS, and face identity preservation metrics demon-
strates that the proposed framework significantly improves reconstruction quality and
perceptual realism compared to traditional enhancement and interpolation approaches.
Keywords:Low-Light Face Super-Resolution, Adaptive Neuro-Fuzzy Inference Sys-
tem (ANFIS), Locality Constrained Representation, Motion Blur Correction, Facial
Image Enhancement, Deep Learning, RRDB, Face Restoration.

1 INTRODUCTION
Nowadays, cameras are used almost everywhere, including surveillance systems, smart-
phones, traffic cameras, and body-worn devices. A common problem with these systems is
that images captured in low-light conditions usually lose important facial details. In many
cases, the images are also blurry or low in resolution, which makes the restoration process
even harder.
In image restoration, the degraded image can be represented mathematically using Eq.
(1).
y=D(k∗x) +n(1)
Here,xrepresents the original image,kis the blur kernel,Drepresents downsampling,
andnrefers to noise added during image capture.
Recovering the original face image from this degraded version is not simple because
multiple types of degradation happen together. Traditional image restoration methods are
mathematically stable, but they usually fail to recover realistic facial textures. On the other
hand, deep learning models such as ESRGAN, GFPGAN, and CodeFormer generate vi-
sually good results, but they sometimes create incorrect facial features or overly smooth
outputs.
In this project, we tried to combine both approaches. The proposed ANFIS-LLFSR
system uses fuzzy logic together with deep learning to improve low-light face restoration.
Instead of applying the same enhancement everywhere, the system first estimates how dark
the image actually is and then adjusts the restoration process accordingly.
Another issue with low-light face images is that many enhancement methods focus only
on increasing brightness. While this improves visibility, it often creates unnatural outputs
where the image looks overexposed or noisy. In face restoration tasks, preserving facial
structure is more important than simply increasing illumination.
Face images also contain very sensitive identity-related features. Small distortions
around the eyes, nose, or mouth can completely change the appearance of a person. Be-
cause of this, restoration models need to improve image quality while still maintaining
facial consistency.
Real-world low-light conditions are also highly unpredictable. Some images may con-
tain motion blur due to camera movement, while others may suffer from compression arti-
facts or sensor noise. A practical restoration framework should therefore be able to handle
multiple degradation types together instead of focusing on only one problem.
This project attempts to address these issues using a combination of fuzzy logic, en-
hancement methods, and deep learning-based reconstruction techniques.
Another reason why low-light restoration has become important is the increasing use of
AI-based surveillance and biometric verification systems. Many of these systems depend
heavily on clear facial images for identification. When the input image quality becomes
poor, the accuracy of these systems decreases significantly.
In practical situations, cameras often operate under uncontrolled lighting conditions.
Street lights, shadows, weather conditions, and camera quality all affect the captured image.
Because of this, a restoration model trained only on ideal datasets may not perform properly

in real environments.
The proposed framework was designed while keeping these real-world challenges in
mind. Instead of focusing only on visual sharpness, the system also attempts to maintain
facial identity and structural consistency.
1.1 Objectives
The main objectives of this project are listed below:
1. Build an ANFIS-based darkness estimation module.
2. Detect and correct motion blur using Wiener deconvolution.
3. Apply Zero-DCE enhancement using the estimated darkness factor.
4. Develop an 8×super-resolution network using Swin Transformer blocks.
5. Preserve facial identity using ArcFace embeddings.
6. Deploy the complete system using FastAPI and a React frontend.
2 LITERATURE SURVEY
Several existing research papers were studied before designing the final pipeline. Each
paper focused on a different problem related to low-light face restoration.
Another important observation from previous research was that many super-resolution
methods perform well only on synthetic datasets. When these models are tested on real
low-light images, the performance often drops because real-world degradations are more
complex.
Some researchers also explored GAN-based approaches for face restoration. These
methods generated visually sharp images but sometimes introduced artificial textures that
did not actually belong to the original face. In biometric applications, such distortions can
become a serious problem.
Some studies also focused on lightweight enhancement methods for mobile devices.
These methods reduced computational complexity but often sacrificed output quality. Real-
time restoration remains difficult because high-quality super-resolution networks usually
require large memory and processing power.
Researchers also experimented with transformer-based restoration models because trans-
formers can capture long-range dependencies more effectively than traditional CNNs. How-
ever, training transformer models requires large datasets and significant computational re-
sources.
These observations helped in selecting a balanced architecture that could provide rea-
sonable restoration quality without becoming excessively complicated.
Fuzzy logic systems were studied separately because they provide interpretable decision-
making instead of black-box predictions. This was one of the main reasons for selecting
ANFIS in the proposed framework.
Overall, the literature survey helped identify the strengths and weaknesses of existing
methods and provided direction for designing the final hybrid architecture.

2.1 ANFIS for Illumination Estimation
Jang introduced the Adaptive Neuro-Fuzzy Inference System (ANFIS), which combines
fuzzy logic with neural networks [1]. The idea behind ANFIS is to make learning systems
more interpretable while still allowing them to adapt during training.
This concept was useful for our project because low-light enhancement depends heavily
on estimating image darkness correctly.
2.2 Zero-DCE
Zero-DCE is a low-light enhancement model that does not require paired training images
[2]. Instead of learning from clean target images, it predicts enhancement curves directly
from the input image.
This method works well for low-light correction because it focuses on brightness ad-
justment while preserving image structure.
2.3 SwinIR
SwinIR uses Swin Transformer blocks for image restoration tasks [3]. Compared to nor-
mal convolutional networks, SwinIR captures both local and global image features more
effectively.
The shifted-window attention mechanism also reduces computational cost while main-
taining good restoration quality.
2.4 ArcFace
ArcFace introduced additive angular margin loss for face recognition tasks [4]. It produces
highly discriminative facial embeddings.
In this project, ArcFace was used to preserve facial identity during restoration so that
the generated face remains similar to the original person.

3.1 System Architecture
The ANFIS-LLFSR system is divided into three main parts: frontend, backend API, and
the restoration pipeline.
The frontend handles image upload and result visualization. The backend controls all
processing stages and connects the frontend with the deep learning models.

3.1.1 Frontend
The frontend was built using React 18, TypeScript, Vite, and Tailwind CSS. Users can
upload images directly through the web interface.
After processing, the frontend displays intermediate outputs such as blur-corrected im-
ages, enhanced images, and final super-resolved results.
The frontend was designed to keep the interface simple and easy to use. Users only need
to upload an image and start the enhancement process. Intermediate outputs are displayed
separately so that users can observe how each stage changes the image.
The interface also helps during debugging because outputs from blur correction, en-
hancement, and super-resolution can be inspected individually. This made testing easier
during development.
Special attention was given to keeping the user interaction simple because the main
goal of the project was image restoration rather than interface complexity. The frontend
mainly focuses on usability and quick visualization of results.
The uploaded images are displayed alongside processed outputs so that differences can
be compared directly.

The backend was developed using FastAPI. The following API endpoints were imple-

The backend handles image decoding, model loading, and output generation.
FastAPI was selected because it is lightweight and works well with machine learning

Error handling was also added to prevent invalid image uploads and unsupported file

image requests.
Batch processing support was also added so that multiple images could be restored
together during testing.
3.1.3 Pipeline Overview
The complete pipeline works in multiple stages. First, the ANFIS module estimates the
darkness level of the image. Then blur correction and illumination enhancement are ap-
plied.
Finally, the super-resolution network reconstructs high-quality facial details.
Each stage in the pipeline depends on the output of the previous stage. If blur correction
is skipped, the super-resolution network may amplify blurry edges instead of restoring
details properly. Similarly, poor illumination enhancement can reduce texture visibility
before reconstruction begins.
Because of this dependency between stages, careful ordering of the pipeline was nec-
essary during system design.
The pipeline was also designed in a sequential manner so that intermediate outputs
could be inspected independently. This helped during experimentation because errors in
one stage could be identified more easily without affecting the entire system.
Another advantage of this modular structure is that future improvements can be inte-
grated more easily. For example, the blur correction stage can later be replaced with a more
advanced deblurring model without changing the remaining pipeline.

3.2 Core Components and Mathematical Formulation
3.2.1 Adaptive Neuro-Fuzzy Inference System
The ANFIS module acts as the main decision-making component of the system. It esti-
mates how dark the image is before enhancement begins.
ANFIS was selected mainly because it combines adaptive learning with fuzzy reason-
ing. Unlike traditional neural networks, fuzzy systems can represent uncertainty more
naturally using linguistic rules.
In low-light images, brightness levels do not always change uniformly across the im-
age. Some regions may already contain enough illumination while other regions remain
extremely dark. Fuzzy inference helps handle these variations more effectively compared
to fixed enhancement strategies.
Another advantage of ANFIS is that the fuzzy rules remain partially interpretable even
after training. This makes the system easier to analyze compared to completely black-box
neural networks.
The adaptive learning capability of ANFIS also helps the system adjust to different
illumination distributions during optimization.
3.3 Feature Extraction
A five-dimensional feature vector is extracted from each image:
• Mean luminance intensity
• Standard deviation
• Entropy
• Gradient energy
• FFT high-frequency ratio
These features help the system understand image brightness, texture quality, and blur
severity.
Feature extraction also helps reduce dependence on raw pixel intensity alone. Since
low-light images can vary significantly depending on camera quality and environment,
combining statistical and frequency-based features improves robustness.
The extracted features were normalized before being passed into the ANFIS module to
maintain stable inference behavior.

3.7.1 Motion Blur Detection
Motion blur was estimated using Laplacian variance, Sobel gradients, and FFT high-frequency
analysis.
If the blur level crossed a threshold, Wiener deconvolution was applied.
The Wiener filter equation is shown in Eq. (6).
ˆF(u, v) =H∗(u, v)
|H(u, v)|2+ 1/SNR·G(u, v)(6)
Blur detection was necessary because many low-light images are captured using longer
exposure times. During long exposure capture, even small camera movement can create
visible blur around facial boundaries.
Applying super-resolution directly on blurred images usually produces poor results.
Therefore, blur correction was applied before enhancement and reconstruction stages.
In low-light photography, motion blur becomes more common because cameras use
slower shutter speeds to capture additional light. Even small hand movements can introduce
blur into facial regions.
This problem becomes more noticeable in surveillance footage where moving subjects
are captured from long distances.
3.7.2 Zero-DCE Enhancement
Zero-DCE predicts enhancement curves for different image regions.
The enhancement function is represented in Eq. (7).
LE(I;α) =I+α(I2−I)(7)
Higher values ofαincrease brightness, while lower values reduce overexposed regions.
One advantage of Zero-DCE is that it does not require paired low-light and normal-
light images during training. Collecting perfectly paired datasets is difficult in real-world
scenarios, so zero-reference enhancement methods become more practical.
The enhancement curves generated by Zero-DCE also help preserve image smoothness
while improving brightness gradually.
Unlike histogram equalization methods, Zero-DCE performs enhancement gradually
instead of applying global brightness changes. This helps preserve more natural illumina-
tion patterns across the image.
The enhancement stage also improves edge visibility, which later helps the super-
resolution network reconstruct sharper facial structures.
3.7.3 Spatial Feature Transform
The SFT layer connects the ANFIS output with the super-resolution network.
The conditioning operation is shown in Eq. (8).
SFT(x, c) =x+α(γ(c)⊙x+β(c))⊙g(c)(8)
This helps the network apply different enhancement strengths based on image darkness.

The SFT layer allows the restoration network to adapt dynamically depending on illu-
mination conditions. Instead of using the same feature scaling everywhere, the conditioning
signal modifies feature maps according to image darkness.
This improves flexibility and helps the network produce more stable outputs under dif-
ferent lighting conditions.
4 SIMULATION PLATFORM AND REQUIREMENTS
4.1 Training Methodology
Figure 4:Training pipeline showing data preparation and hybrid ANFIS optimization.
4.1.1 Dataset Preparation
The CelebA dataset was used for training and evaluation. It contains more than 200,000
aligned face images.
For super-resolution training, the images were resized and degraded using synthetic
low-light transformations and motion blur.
Gamma correction was applied to simulate dark environments.
The CelebA dataset was selected because it contains large variations in facial pose,
lighting conditions, and expressions. These variations make the dataset suitable for training
robust face restoration models.
Different degradation levels were applied artificially to simulate realistic low-light con-
ditions. This helped the model learn restoration under multiple difficulty levels instead of
memorizing specific degradation patterns.
4.1.2 Training Details
The ANFIS module and restoration networks were trained using Adam optimizer.
The main training settings are listed below:
• Epochs: 200
• Batch Size: 1024
13
--- Page 19 ---
• Learning Rate:1×10−3
• Gradient Clipping: max_norm = 1.0
The learning rate was reduced gradually during training to improve convergence.
Training deep learning models for image restoration required significant computational
resources. GPU acceleration was used during training to reduce execution time and im-
prove optimization efficiency.
Different hyperparameter combinations were tested before selecting the final configu-
ration. Smaller batch sizes produced unstable training results, while very large learning
rates caused divergence during optimization.
4.1.3 Fine-Tuning
Multiple loss functions were combined during end-to-end training.
The complete loss function is shown in Eq. (9).
L=λ 1Lsc+λ 2Lexp+λ 3Lcol+λ 4Lis+λ 5Lid+λ 6Llm (9)
Different weights were used to balance illumination correction, perceptual quality, and
identity preservation.
Training stability was monitored continuously during experimentation. In the early
stages of training, some outputs appeared noisy because the network had not yet learned
stable feature mappings.
As training progressed, reconstructed outputs gradually became sharper and more visu-
ally consistent.

Different evaluation metrics were used to measure restoration quality.
• PSNR

PSNR and SSIM measure image quality, while LPIPS focuses more on perceptual sim-
ilarity.

No single metric is sufficient for evaluating face restoration quality. Some metrics focus
mainly on pixel similarity, while others evaluate perceptual realism.
Because of this, multiple evaluation metrics were used together to provide a more bal-

6 CONCLUSION
6.1 Conclusion
In this project, we developed a hybrid low-light face restoration system using ANFIS and
deep learning.
The proposed pipeline was able to improve image brightness, restore facial details, and
preserve identity more effectively compared to baseline methods.
Using fuzzy logic for darkness estimation helped the system apply more controlled
enhancement instead of treating all images in the same way.
The final results showed improvements in PSNR, SSIM, LPIPS, and face recognition
accuracy.
Overall, the project demonstrated that combining interpretable fuzzy systems with deep
learning can produce reliable results for low-light face restoration.
6.2 Future Work
Several improvements can still be made in the future.
1. Real-time optimization using FAISS.
2. Video-based face restoration.
3. Replacing SwinIR with newer transformer architectures.
4. Federated learning on private datasets.
5. Better blur kernel estimation methods.
Another possible improvement would be reducing inference time so that the system can
work efficiently on mobile devices or embedded systems. Real-time face restoration could
become useful in surveillance cameras and video conferencing applications.
Future work could also include testing the framework on larger real-world datasets
collected under uncontrolled illumination conditions.
Another possible extension would be integrating diffusion-based restoration models,
which have recently shown promising performance in image generation and reconstruction
tasks.
Further optimization could also improve inference speed and reduce GPU memory us-
age during deployment.
