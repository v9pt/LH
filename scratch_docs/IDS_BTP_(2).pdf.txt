ABSTRACT
Intrusion Detection Systems (IDS) are essential components of modern cybersecu-
rity infrastructures, responsible for monitoring network traffic and identifying malicious
activities. Traditional IDS frameworks commonly rely on fixed-size sliding windows
for processing streaming network data. However, static window sizes introduce a major
trade-off between detection responsiveness and classification stability. Small windows
react quickly to sudden attacks but are highly sensitive to noise, whereas large windows
provide stable predictions but fail to adapt rapidly to evolving threats and concept drift.
This project proposes an adaptive sliding window Intrusion Detection System driven
by Reinforcement Learning (RL). The proposed framework integrates a supervised
Random Forest-based IDS classifier with a Deep Q-Network (DQN) agent capable of
dynamically selecting optimal window sizes during real-time traffic analysis. The RL
agent continuously observes detection performance metrics and traffic behavior, then
learns adaptive windowing strategies that maximize long-term intrusion detection per-
formance while minimizing false negatives and unstable behavior.
The system is evaluated using two benchmark intrusion detection datasets: NSL-
KDD and CIC-IDS2017. A realistic streaming environment is simulated to emulate
real-world network conditions. Experimental results demonstrate that the RL-based
adaptive framework consistently improves detection effectiveness compared to tradi-
tional static-window baselines. The adaptive agent successfully reduces false negatives,
improves responsiveness during attack-heavy periods, and maintains high precision un-
der stable traffic conditions.
The findings of this work demonstrate that Reinforcement Learning-driven adap-
tive window control is a promising direction for next-generation intelligent IDS archi-
tectures. By dynamically balancing responsiveness and stability, the proposed system
offers improved robustness, scalability, and adaptability for modern cybersecurity envi-
ronments.
Keywords:Intrusion Detection System, Reinforcement Learning, Deep Q-Network,
Adaptive Sliding Window, Cybersecurity, Random Forest, Concept Drift, Network Se-
curity.

CHAPTER 1 INTRODUCTION AND LITERATURE REVIEW
1.1 Motivation
The motivation for this research is rooted in the critical failure of static security mech-
anisms to keep pace with the increasingly dynamic and adversarial nature of modern
network infrastructures. Traditional Intrusion Detection Systems (IDS) rely heavily on
a fixed temporal aggregation approach, where a pre-defined window ofNpackets or
flows is accumulated before being fed into a classification model. This design choice
creates a fundamental “Accuracy-vs-Responsiveness” dilemma that cannot be resolved
through conventional supervised learning alone.
This work is specifically motivated by the following industrial and scientific chal-
lenges:
1.Non-Stationarity and Concept Drift:
Real-world network traffic is inherently non-stationary. Patterns of benign ac-
tivity evolve due to changing user behaviors, while attack signatures shift as ad-
versaries develop new evasion techniques. Static systems, constrained by fixed
data observation scales, often suffer from “Concept Drift,” where their detection
accuracy decays rapidly as the traffic distribution moves away from the training
baseline.
2.The Latency Bottleneck in High-Velocity Attacks:
In high-speed environments, such as multi-gigabit data centers or IoT gateways,
detection speed is as critical as accuracy. A fixed large window provides statistical
stability but introduces significant detection latency, allowing rapid attacks (like
SYN Floods or Port Scans) to complete their objective before the system even
triggers an alert. Conversely, small windows improve reaction time but are highly
susceptible to network “noise,” resulting in an overwhelming volume of False
Positives.
3.The Complexity of Manual Parameter Tuning:
Current IDS solutions require significant manual effort from security analysts to
tune sensitivity thresholds and window sizes for specific network segments. In a

modern Security Operation Center (SOC), this leading to “alert fatigue” and hu-
man error. There is a critical need for an autonomous “Meta-Controller” that can
learn to self-optimize these parameters in real-time without human intervention.
4.Bridging the Gap Between Research and Deployment:
While deep learning has improved classification scores, many state-of-the-art
models are too computationally expensive for live, high-throughput deployment.
This project is motivated by the need for a Hybrid Architecture—combining the
raw speed of a Random Forest detector with the intelligent, adaptive oversight of
a Dueling Double Deep Q-Network (D3QN).
By transforming critical IDS parameters from static hyperparameters into learnable
decision variables, this research aims to build a system that is not just accurate, but truly
adaptive to the fluid reality of modern cyber threats.
1.2 Key Challenges
The development of an autonomous and adaptive intrusion detection framework in-
volves overcoming several multi-disciplinary hurdles that span network security and
machine learning. These challenges include:
1.Dynamic Adaptation under Non-Stationary Distributions:
The primary challenge in real-time intrusion detection is the statistical evolution
of network telemetry. As legitimate traffic patterns shift and adversarial tactics
change, a static model becomes obsolete. Proactively identifying these shifts and
adjusting the observation granularity without manual reconfiguration is a signifi-
cant technical difficulty.
2.Computational Overhead and Real-Time Constraints:
The IDS must operate at industrial scale while adapting to changing traffic dis-
tributions. The proposed framework achieved an average throughput of 29,865
flows/sec and a peak throughput of 69,417 flows/sec during real-time simulation,
demonstrating its suitability for high-volume enterprise environments. Although
the primary intrusion detector is based on a lightweight Random Forest classifier,
the D3QN meta-controller utilizes a neural network for adaptive policy inference.
Consequently, the system must ensure that the additional computational overhead
introduced by deep reinforcement learning and periodic classifier retraining does
not significantly impact end-to-end detection latency or throughput.
3.The Exploration-Exploitation Dilemma in Adversarial Contexts:
2
--- Page 15 ---
In a reinforcement learning framework, the agent must balance the exploration
of new window sizes and thresholds with the exploitation of known optimal set-
tings. In a security context, excessive exploration may lead to transient periods
of low sensitivity, providing a window of opportunity for an attacker to remain
undetected.
4.Severe Class Imbalance and Reward Sparsity:
Network traffic is characterized by a massive volume of benign data points and
relatively rare malicious instances. This imbalance leads to a sparse reward signal
for the reinforcement learning agent, as the opportunities to learn from success-
ful attack detections are infrequent. Maintaining high recall for minority attack
classes while minimizing false alarms is a persistent challenge.
5.High-Dimensional Feature Engineering and Redundancy:
Modern datasets such as CIC-IDS2017 contain dozens of complex statistical fea-
tures. Many of these attributes are redundant or exhibit high correlation, which
can lead to overfitting and increased processing times. Selecting a robust sub-
set of features that remains relevant across different network segments and attack
types is essential for maintaining model generalizability.
1.3 Problem Addressed in Thesis
This thesis addresses the critical limitation of hyperparameter rigidity in contemporary
Intrusion Detection Systems. Current machine learning-based IDS architectures rely
on static configurations for data observation scales and classification sensitivity. These
fixed parameters are typically optimized for a specific training distribution and fail to
maintain their effectiveness when deployed in live, non-stationary network environ-
ments.
The specific technical problems targeted in this research include:
1.The Static Window Bottleneck:
Conventional systems process network flows using a fixed sliding window size.
This approach fails to account for the temporal variance of network traffic. A
single static window cannot simultaneously provide the high responsiveness re-
quired for rapid bursts of malicious activity and the long-term stability needed to
reduce false positives during benign operations.
2.Fixed Detection Thresholds:
Most detection models utilize a default probability threshold of 0.5 for classifi-
cation. However, the optimal threshold varies depending on the current network

--- Page 16 ---
risk level and the specific attack surface being targeted. The absence of a mech-
anism to dynamically adjust this threshold leads to suboptimal performance in
adversarial scenarios where attack signatures are stealthy or evolve over time.
3.The Decay of Supervised Models under Concept Drift:
Once a supervised model is trained and deployed, its precision typically degrades
as the underlying network traffic patterns change. This research addresses the
lack of integrated online retraining loops that can autonomously rebalance and
update the model based on performance feedback without human intervention.
4.Inefficiency of Pure Deep Learning Approaches:
While deep learning models can achieve high accuracy, they often lack the through-
put required for high-speed network gateways. This work addresses the need for
a hybrid framework that utilizes computationally efficient supervised classifiers
overseen by an intelligent reinforcement learning meta-controller to achieve both
speed and adaptability.
By formulating the IDS management process as a learnable control task, this re-
search provides a methodology for transforming these static hyperparameters into dy-
namic variables that respond to real-time network telemetry and prediction uncertainty.
1.4 Approach to the Problem and Organization of Thesis
The approach adopted in this research involves the design and implementation of a hy-
brid framework that integrates supervised classification with deep reinforcement learn-
ing. Rather than replacing traditional detection models, this research introduces a meta-
control layer that dynamically supervises the operational parameters of the IDS.
The core of this approach is a Dueling Double Deep Q-Network (D3QN) agent
that learns an optimal policy for adjusting two critical variables: the data observa-
tion window size and the detection probability threshold. The agent receives a multi-
dimensional state vector representing current classifier performance, prediction uncer-
tainty, and network traffic volatility. By maximizing a custom reward function based
on the Matthews Correlation Coefficient and F1-score, the agent learns to balance the
trade-off between sensitivity and stability. Furthermore, the framework incorporates an
online retraining module that utilizes synthetic oversampling techniques to ensure the
underlying classifier remains robust against class imbalance and concept drift.

1.5 Literature Survey
The field of Intrusion Detection Systems (IDS) has evolved from static, rule-based ar-
chitectures to autonomous frameworks capable of operating in non-stationary network
environments. This section provides a comprehensive review of the state-of-the-art
research that informs the current work, categorized by their contributions to adaptive
windowing and reinforcement learning-based security.
Foundational Benchmarks and Adaptive Windowing
The benchmark for modern IDS evaluation was established by Sharafaldin et al. (2018),
who introduced the CIC-IDS2017 dataset and demonstrated that a supervised Ran-
dom Forest baseline could achieve an F1-score of 96.5%. However, this work uti-
lized static processing windows, leaving the system vulnerable to temporal fluctuations.
Early attempts to address this rigidity include the work of Eskin et al. (2000), which
achieved approximately 88% accuracy using on-the-fly model building. More recently,
Suryawanshi et al. (2022) proposed a heuristic-driven adaptive window combined with
Recurrent Neural Networks (RNN), achieving 94.2% accuracy by responding to error
signals. Similarly, Iqbal et al. (2020) leveraged deep learning for time-varying window
sizing, reporting an F1-score of 91.5%.
Concept Drift and Reactive Adaptation
Handling the statistical evolution of network traffic, or concept drift, is a recurring
theme in recent literature. Andresini et al. (2021) developed a reactive framework
where concept drift detection triggers model updates, achieving 96.1% accuracy. While
effective, this approach remains reactive rather than proactive. The ADWISE (2023)
5
--- Page 18 ---
framework introduced a more sophisticated drift-aware windowing mechanism using
heuristic-based hyperparameter optimization (HPO), reaching over 98% accuracy on
the NSL-KDD dataset. However, these methods rely on predefined rules rather than an
agent-based decision policy.
Deep Reinforcement Learning (DRL) in IDS
The application of DRL has significantly enhanced the classification and feature se-
lection capabilities of IDS. The ID-RDRL framework proposed by Ren et al. (2024)
utilizes DRL for recursive feature selection, achieving an F1-score of 97.8% on the
CSE-CIC-IDS2018 dataset. Alavizadeh et al. (2021) proposed a Deep Q-Learning
(DQL) model that achieved 98.4% accuracy on NSL-KDD by focusing on classifica-
tion stability. Chen et al. (2022) presented a DRL framework for anomaly detection
in data streams, achieving a precision of 97.2%. In the domain of IoT security, Otoum
et al. (2022) applied RL to dynamic environments, reaching a detection accuracy of
98.2%, while Khamis et al. (2021) achieved 93.5% accuracy for botnet detection using
classic Q-learning.
Meta-Control and Dynamic Temporal Aggregation
The most direct predecessor to this research is the RL-Window approach introduced
by Zarghani and Abedi (2025). They utilized a Dueling Deep Q-Network (DQN) to
optimize sliding window sizes in generic multi-dimensional data streams, achieving
over 94% accuracy in financial and sensor applications. Similarly, Litty et al. (2025)
explored RL-based windowing for high-velocity streams, reporting approximately 95%
accuracy.
Despite these advancements, a significant gap remains: existing research either fo-
cuses on RL for classification (ID-RDRL, Alavizadeh) or RL for windowing in non-
adversarial streams (Zarghani, Litty). This thesis bridges these domains by implement-
ing a Hybrid Dueling Double DQN (D3QN) Meta-Controller that simultaneously opti-
mizes window size and detection thresholds within the specific, high-velocity context
of network intrusion detection.

The preprocessing phase is critical for transforming raw network telemetry into a struc-

2.2.1 Processing of Connection-Level Data
For connection-level telemetry, such as that found in the NSL-KDD benchmark, the

The following steps are implemented:

1.Categorical Feature Transformation:

2.6 Reinforcement Learning Formulation
The problem of dynamically optimizing the operational parameters of an IDS is formu-
lated as a Markov Decision Process (MDP). This mathematical framework provides a
structured method for an autonomous agent to learn an optimal policy through sequen-
tial interactions with a non-stationary environment. Unlike supervised learning, which
maps inputs to labels, the MDP formulation allows the system to map network states to
high-level control actions that maximize long-term security performance.
2.6.1 The MDP Tuple
The control problem is defined by the quintuple(S, A, P, R, γ), where:
1.State Space (S):
A continuous, multi-dimensional representation of the current network environ-
ment and classifier health.
2.Action Space (A):
16
--- Page 29 ---
A discrete set of decisions representing the available combinations of temporal
window sizes and probability thresholds.
3.Transition Function (P):
The probability of moving from one network state to another given a specific
control action. In the context of intrusion detection, this function is typically
unknown and highly complex due to the stochastic nature of network traffic, ne-
cessitating a model-free reinforcement learning approach.
4.Reward Function (R):
A scalar feedback signal that quantifies the effectiveness of the chosen param-
eters in detecting intrusions while minimizing false alarms and computational
overhead.
5.Discount Factor (γ):
A parameter that determines the importance of future rewards relative to immedi-
ate feedback. This study utilizes a discount factor of 0.99 to encourage the agent
to learn a policy that ensures sustained long-term security rather than short-term
accuracy spikes.

2.6.2 Comparison with Existing IDS Formulations
In much of the earlier literature, such as the work by Khamis et al. (2021), the state

this allowed the agent to perform classification, it did not provide the necessary context

2.6.3 Interaction Dynamics
The interaction between the D3QN agent and the IDS environment proceeds in discrete
time steps. At each stept, the agent observes the states tderived from the previous
window of traffic. It then selects an actiona twhich dictates the size of the next flow
batch and the sensitivity of the detector for that batch. After the batch is processed,
the environment computes the rewardr tbased on the detection results and provides the
next states t+1. This closed-loop interaction ensures that the agent receives continuous
feedback on the consequences of its parameter selections, allowing it to converge toward
a policy that balances the competing objectives of the system.
By formalizing the problem as an MDP, this study moves beyond simple heuristic
adaptation and provides a rigorous mathematical basis for autonomous decision-making
in network security.
2.7 State Representation
The state representation is the information through which the reinforcement learning
agent perceives its environment. In this research, a multi-dimensional state vector is
designed to provide the agent with a holistic view of both the network traffic charac-
teristics and the operational health of the underlying classifier. This representation is
critical for enabling the agent to make informed decisions regarding window size and
detection thresholds.
2.7.1 Components of the 6D State Vector
Unlike conventional IDS research that often utilizes raw packet features as the state,
this study implements a performance-centric 6D vector. The components of the states t
at any time steptare as follows:
1.F1-Score:

The harmonic mean of precision and recall for the most recent traffic window.

2.Precision and Recall:

3.Classification Uncertainty:

2.9.2 Technical Rationale and Research Comparison
The design of this action space addresses a significant gap identified in previous studies.
Most existing adaptive IDS research, such as the work by Suryawanshi et al. (2022) and

window adaptation is effective for handling concept drift, it does not directly address
the sensitivity requirements of different attack vectors.
By incorporating dynamic thresholding into the action space, this framework builds

significantly between high-volume DDoS attacks and stealthy, low-frequency infiltra-

2.9.3 Impact on System Posture
The discrete nature of the action space provides stability during the training process,
as it prevents the agent from making infinitesimally small or erratic changes that could
lead to oscillation. By selecting from these 28 strategically chosen configurations, the
D3QN agent can effectively re-posture the entire IDS in response to shifting network
states, achieving a level of adaptability that static systems cannot replicate.
2.10 Deep Q-Network Architecture
The meta-controller in this research is implemented using an advanced reinforcement
learning architecture known as the Dueling Double Deep Q-Network (D3QN). This
architecture is specifically chosen for its ability to provide stable and efficient learning
in high-dimensional state spaces where certain states have much higher intrinsic value
than the specific actions taken within them.

2.10.1 The Dueling Network Design
The core innovation of the dueling architecture is the decomposition of the Q-function
into two separate streams: a state-value streamV(s)and an action-advantage stream
A(s, a).
1.Feature Extraction Layer:
Both streams share a common input layer consisting of two fully connected neural
layers with 128 neurons each, utilizing Rectified Linear Unit (ReLU) activation
functions. This layer learns the fundamental representations of network perfor-
mance and traffic volatility.
2.State-Value Stream (V):
This stream estimates the scalar value of being in a particular network state, re-
gardless of the chosen window size or threshold. It consists of a 64-neuron hidden
layer followed by a single output neuron.
3.Action-Advantage Stream (A):
This stream estimates the relative importance of each of the 28 possible actions
for the current state. It comprises a 64-neuron hidden layer followed by 28 output
neurons.
4.Aggregation Layer:
The outputs are combined using a specialized aggregation module:

This mean-centering approach improves training stability by decoupling the esti-
mation of state value from the specific advantage of an action, a technique cited
in recent literature as superior for control tasks with many redundant actions pro-
posed by Wang et al. [10].
2.10.2 Double DQN Stabilization
To address the common problem of Q-value overestimation found in standard Deep
Q-Networks, this framework incorporates the Double DQN (DDQN) refinement.
1.Online and Target Networks:
The system maintains two identical neural networks—an online network for se-
lecting actions and a target network for calculating the temporal-difference target.
23
--- Page 36 ---
2.Action Selection Decoupling:
During the update step, the online network is used to select the best action for the
next state, while the target network is used to estimate the Q-value for that action.
This prevents the agent from aggressively propagating overly optimistic value
estimates, leading to more robust convergence on the non-stationary distributions
of the CIC-IDS2017 dataset [11].
2.10.3 Comparison with Existing Architectures
The use of D3QN represents a significant technical upgrade over the models described
in earlier IDS research. While works such as ID-RDRL (2024) and the Botnet detection
study by Khamis et al. (2021) utilized standard Deep Q-Networks, they frequently
encountered stability issues when traffic patterns shifted abruptly.
By building upon the Dueling architecture utilized in the RL-Window framework
(Zarghani and Abedi, 2025) and adding the Double DQN stabilization layer, this re-
search provides a meta-controller capable of maintaining a coherent adaptation policy
even during extreme network volatility.
2.11 Training Hyperparameters
The convergence and stability of the D3QN meta-controller are highly dependent on the
selection of training hyperparameters. In this research, these parameters were meticu-
lously tuned to accommodate the high-velocity and imbalanced nature of the network
telemetry datasets. This section details the specific configuration used for the reinforce-
ment learning process.
2.11.1 Optimizer and Learning Rate
The Dueling Deep Q-Network is optimized using the Adam (Adaptive Moment Esti-
mation) optimizer.
1.Learning Rate:
A learning rate of5×10−4is utilized. This value was chosen to provide a balance
between rapid policy discovery and long-term convergence stability.
2.Gradient Clipping:
To prevent the exploding gradient problem common in deep reinforcement learn-
ing, the system implements a smooth L1 loss (Huber loss) which is less sensitive
to outliers in the temporal-difference error [18].

--- Page 37 ---
2.11.2 Experience Replay and Mini-Batching
To decorrelate the training data and improve the efficiency of each learning step, a
prioritized experience replay mechanism is employed.
1.Replay Buffer Capacity:
The buffer stores the most recent 20,000 transitions (tuples of state, action, re-
ward, and next state). This capacity ensures that the agent can sample from a
diverse history of network behaviors, including rare attack events.
2.Mini-Batch Size:
Samples are processed in mini-batches of 128 transitions. This batch size is sig-
nificantly larger than the standard 32-sample batch used in earlier works like
Khamis et al. (2021). The larger batch size provides a more stable estimation
of the gradient, which is critical when dealing with the high variance found in
CIC-IDS2017 traffic.
2.11.3 Exploration-Exploitation Strategy
The agent’s exploration policy is managed using an epsilon-greedy strategy.
1.Initial Epsilon (ϵ):
Training begins with an epsilon of 1.0, forcing the agent to explore all 28 actions
randomly to understand the environment.
2.Decay Rate:
The epsilon value is decayed by a factor of 0.97 at the end of each training
episode. This gradual reduction allows the agent to shift from random explo-
ration to informed exploitation of the learned policy.

2.11.4 Temporal Dynamics and Synchronization
1.Discount Factor (γ):

By aligning these hyperparameters with the best practices established in recent deep

flow-level benchmarks.
2.12 Training Procedure
The training procedure in this research follows a dual-objective approach, where the
reinforcement learning meta-controller learns to adapt decision parameters while the
underlying supervised classifier simultaneously updates its internal model to mitigate
concept drift. This section describes the systematic workflow executed during the 50-
episode training phase.
2.12.1 The Reinforcement Learning Execution Loop
The primary training loop manages the interaction between the D3QN agent and the
network data stream. For each episode, the following sequence is performed:
1.State Observation:
The environment constructs a 6D state vector representing the performance and
volatility of the previous window.
2.Action Selection:
The agent selects an action index using the epsilon-greedy strategy, which is de-
coded into a specific(Threshold, Window)pair.
3.Flow Slicing and Inference:
The environment advances the data pointer by the chosen window size and re-
trieves the corresponding flows. The Random Forest model then classifies these
flows using the chosen probability threshold.
26
--- Page 39 ---
4.Reward Calculation:
The system computes the scalar reward based on the F1-score, MCC, and a win-
dow efficiency penalty.
5.Experience Storage and Policy Update:
The transition(s t, at, rt, st+1)is stored in the experience replay buffer. A mini-
batch of 128 transitions is sampled to update the weights of the dueling neural
network using temporal-difference learning.
2.12.2 Online Classifier Retraining and Resampling
A significant technical contribution of this research is the implementation of an in-
tegrated online retraining mechanism for the Random Forest detector. Unlike many
studies that utilize a static model (e.g., Khamis et al., 2021), our framework ensures the
classifier evolves with the traffic.
1.Incremental Buffering:
As flows are processed, they are accumulated in a secondary retraining buffer.
2.Trigger Mechanism:
Upon reaching a threshold of 5,000 processed samples, an automated retraining
event is triggered.
3.Synthetic Oversampling:
To address the severe class imbalance inherent in intrusion datasets, the retraining
module utilizes Random Over-Sampling or SMOTE (Synthetic Minority Over-
sampling Technique). This procedure ensures that the classifier maintains its sen-
sitivity to rare attack classes (such as U2R or R2L) even when benign traffic
dominates the stream [9].
2.12.3 Comparison with Conventional Training Workflows
The training procedure implemented here builds upon the reactive retraining concepts
proposed by Andresini et al. (2021) but integrates them directly into the agent’s learning
cycle. By combining the proactive parameter adjustment of the D3QN agent with the
reactive weight updates of the Random Forest model, the framework achieves a state of
“Hybrid Adaptability.”
This approach ensures that the system is not only learning how to observe the data
better (Window size) and how to judge the data more effectively (Threshold), but also
how to better represent the underlying data distribution through continuous retraining.

--- Page 40 ---
2.12.4 Convergence Monitoring
During the training process, several indicators are monitored to ensure convergence.
These include the average episodic reward trajectory, the stabilization of the Q-value
estimations, and the decay of the exploration rate. This rigorous procedure ensures that
the resulting policy is robust enough for the final evaluation phase on unseen test data.
2.13 Adaptive Evaluation
The final evaluation of the hybrid IDS framework is designed to quantify the perfor-
mance gains achieved by the learned policy compared to static baselines. In this study,

2.13.1 Greedy Evaluation Protocol
To ensure the scientific validity of the results, the evaluation phase implements a “Scien-
tific Evaluation Gate.” Unlike the training phase, which utilizes a stochastic exploration
strategy, the evaluation phase is strictly deterministic.
1.Epsilon-Zero Configuration:

the exploitation of the “learned optimal intelligence.”
2.Frozen Meta-Policy:
While the underlying Random Forest model continues to utilize its online re-
training capabilities if specified, the parameters of the D3QN neural network are
frozen. This ensures that the reported metrics reflect the performance of a stable,
converged policy.
2.13.2 Simulation of the Test Stream
The evaluation is performed using a specialized simulation environment that processes
the KDDTest+ and CIC-IDS2017-Test subsets as a continuous, high-velocity stream.
1.Sequential Decision-Making:
The agent processes the test data in a single pass. At each step, it observes the 6D
state of the previous window and selects the window size and threshold for the
subsequent segment.

3.7.1 Multi-Threaded Simulation Architecture
The system utilized a multi-threaded producer-consumer architecture to mimic real-
world network arrival patterns.
1.Producer Thread:
The producer thread simulates a high-speed telemetry stream by populating a syn-

2.Consumer Thread:
The consumer thread represents the Adaptive IDS Agent operating in pure greedy
mode. This thread extracts the network state, queries the trained D3QN policy for
the optimal window and threshold, and executes inference on the current batch.
This architecture ensures that the detection engine is evaluated under realistic back-
pressure conditions, demonstrating that the meta-control logic does not introduce sig-
nificant processing bottlenecks.

4.1 Task, Achievement and Possible Beneficiaries
The primary task of this research was to develop a hybrid intrusion detection system
capable of autonomous adaptation to the non-stationary nature of modern network traf-
fic. This objective was successfully achieved through the implementation of a Dueling
Double Deep Q-Network meta-controller that dynamically optimizes the operational
parameters of a supervised Random Forest worker.
The achievement of the project is demonstrated by the significant performance gains
observed across two heterogeneous benchmarks. The system achieved an 80.81% F1-
score on the challenging NSL-KDD Test+ subset and a 97.25% F1-score on the complex
CIC-IDS2017 flow dataset. Furthermore, the development of a real-time simulation
engine demonstrated that the framework can sustain an average throughput of 29,865
flows per second, making it suitable for Gigabit-scale enterprise environments.
The possible beneficiaries of this research include Security Operations Center teams
that face increasing alert fatigue from static IDS frameworks. By reducing false pos-
itives by nearly 50%, the proposed framework enables analysts to focus on higher-
confidence alerts and improves operational efficiency.
Additionally, small and medium-sized enterprises can benefit from the autonomous
tuning capabilities of the framework, reducing dependence on continuous manual pa-
rameter optimization by experienced network administrators.
The research also provides a valuable architectural template for academic researchers
seeking to combine the computational efficiency of traditional machine learning with
the adaptive intelligence of reinforcement learning.
4.2 Review of Contributions
This research has made several original contributions to the field of adaptive network
security.
The first major contribution is the introduction of a dual-parameter control mecha-
nism. Unlike prior studies that focused exclusively on window adaptation, the proposed
framework simultaneously optimizes both the decision threshold and the observation
55
--- Page 68 ---
window size, resulting in a more granular and responsive security posture.
The second contribution is the application of the Dueling Double DQN architecture
for IDS meta-control. This architectural choice mitigated the overestimation problems
commonly observed in reinforcement learning systems and enabled stable convergence
within 50 episodes. The separation of state value and action advantage allowed the
framework to remain robust even under the extreme class imbalance conditions typical
of intrusion detection datasets.
The third contribution is the end-to-end validation of the framework using industry-
standard tooling. By integrating the system with the NFStreamer library and validating
performance using live Wiresharkpcapngcaptures, the project extends beyond theo-
retical offline analysis. The successful mapping of raw packet telemetry into structured
flow features provides a practical roadmap for deploying adaptive AI-driven security
systems in real-world environments.
4.3 Scope for Future Work
While the current framework demonstrates strong effectiveness, several opportunities
for future expansion remain.
One major area for future development involves scaling the framework for 10 Gbps
and 100 Gbps network backbones. Achieving this objective would require migrating
portions of the detection pipeline to high-performance implementations using languages
such as C++ or utilizing hardware acceleration through Field Programmable Gate Ar-
rays (FPGAs).
A second research direction involves integrating Federated Learning into the train-
ing pipeline. This would enable multiple organizations to collaboratively train the
D3QN meta-controller without directly sharing sensitive packet telemetry, thereby pre-
serving privacy while improving exposure to diverse attack patterns.
A third avenue for future work involves the incorporation of Graph Neural Networks
for detecting lateral movement and multi-stage attacks. While the current flow-based
architecture performs well for isolated intrusion detection, graph-based representations
could improve the system’s ability to model relationships between network entities and
identify advanced persistent threat behaviors.
Finally, the exploration of Transformer-based sequence modeling architectures could
further improve the detection of slow, low-rate, and temporally distributed attack pat-
terns that evolve across extended observation windows.
